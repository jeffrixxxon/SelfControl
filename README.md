# SelfControl

Telegram-бот с мини-приложением для контроля жизни: финансы, здоровье, спорт. Внутри работает Claude: он понимает обычные сообщения, голосовые, фото чеков и документы и сам ведёт записи.

## Что умеет

| Раздел | Возможности |
|---|---|
| 💰 Деньги | Расходы и доходы по категориям, месячные лимиты (общий и по категориям), долги «я должен / мне должны» с частичными погашениями |
| 🧾 Чеки | Фото чека → Claude распознаёт позиции и разносит расходы по категориям |
| 📄 Документы | PDF, фото рецепта, счёт, квитанция → краткий разбор и предложение действий (записать расход, добавить лекарства) |
| 🍎 Питание | Приёмы пищи с КБЖУ; по фото или описанию Claude оценивает калории; дневная цель |
| 💊 Лекарства | Курсы с расписанием, напоминания с кнопками «Принял / Пропустил», отметки приёма |
| ⚖️ Вес | Замеры, график, ИМТ, целевой вес |
| 🏋️ Тренировки | Тип, длительность, упражнения (подходы × повторы × вес), недельная статистика |
| 🎯 Цели | Цели по любым сферам с прогрессом и сроком |
| ⏰ Напоминания | Разовые и повторяющиеся по дням недели; тип «мотивация» — Claude пишет персональное сообщение по вашим данным |
| 🌙 Итоги дня | Вечером Claude присылает короткий разбор: деньги, еда, лекарства, активность |
| 🎙 Голос | Голосовые в боте и запись голоса в мини-аппе, расшифровка через Whisper |

Примеры сообщений боту:
- «Купил продукты на 1850»
- «Занял Саше 5000 до конца месяца»
- «Пью омепразол 20 мг в 8:00 и 20:00 две недели»
- «Пробежал 5 км за 28 минут»
- «Сколько я потратил на кафе в этом месяце?»

## Архитектура

```
SelfControl_Project/
├── docker-compose.yml       Postgres + backend + Caddy (HTTPS и раздача мини-аппа)
├── .env.example             все настройки
├── backend/                 Python 3.12
│   └── app/
│       ├── main.py          FastAPI + бот (aiogram 3, long polling) + планировщик в одном процессе
│       ├── models.py        таблицы (SQLAlchemy 2, async)
│       ├── auth.py          проверка подписи Telegram initData и мультипользовательский доступ
│       ├── api/             REST API мини-аппа (/api/...)
│       ├── bot/             хендлеры: текст, голос, фото, документы, кнопки лекарств
│       └── services/
│           ├── assistant.py Claude: системный промпт, цикл tool use, история диалога
│           ├── tools.py     23 инструмента, которыми Claude управляет данными
│           ├── core.py      общая бизнес-логика для API и Claude
│           ├── transcribe.py  Whisper (локально или через OpenAI)
│           └── scheduler.py напоминания, мотивация, вечерние отчёты
└── webapp/                  React 18 + Vite + TypeScript, тема берётся из Telegram
```

Каждый пользователь видит только свои данные: все записи привязаны к `user_id`, а мини-апп авторизуется по подписанному Telegram `initData`.

## Запуск на VPS

Нужны: VPS с Docker (от 2 ГБ RAM для локального Whisper, иначе 1 ГБ и `TRANSCRIBE_PROVIDER=openai`) и домен.

1. **Бот.** В @BotFather выполните `/newbot` и сохраните токен.
2. **Домен.** Создайте A-запись домена на IP сервера.
3. **Ключ Claude.** Получите на [console.anthropic.com](https://console.anthropic.com).
4. **Настройки:**
   ```bash
   cp .env.example .env
   nano .env   # BOT_TOKEN, DOMAIN, WEBAPP_URL, ANTHROPIC_API_KEY, POSTGRES_PASSWORD
   ```
5. **Запуск:**
   ```bash
   docker compose up -d --build
   docker compose logs -f backend
   ```
   Caddy сам выпустит HTTPS-сертификат. Бот при старте сам настроит кнопку меню «SelfControl» и список команд.
6. В @BotFather можно привязать мини-апп к профилю бота: `/newapp`, URL = `WEBAPP_URL`.

Первое голосовое в режиме `local` обработается медленнее, потому что скачивается модель Whisper (~500 МБ). Затем она хранится в томе `appdata`.

### Если что-то не запускается

- `socket.gaierror: Name or service not known` при старте backend означает, что бэкенд не нашёл базу. Проверьте, что всё запущено через `docker compose up` (а не `docker run`), что сервис `db` работает (`docker compose ps`), и что в `.env` нет своей строки `DATABASE_URL`: адрес базы собирается автоматически.
- В логе backend при старте пишется `База подключена: postgresql+asyncpg://db:5432/selfcontrol`. Пока база поднимается, бэкенд делает до 30 попыток подключения.

### Обновление
```bash
git pull   # или скопируйте новые файлы
docker compose up -d --build
```

### Резервная копия базы
```bash
docker compose exec db pg_dump -U selfcontrol selfcontrol > backup_$(date +%F).sql
```

## Локальная разработка

```bash
# Бэкенд (SQLite, без Telegram-авторизации)
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
DEBUG=true DEV_TG_ID=1 ANTHROPIC_API_KEY=... uvicorn app.main:app --reload

# Мини-апп (проксирует /api на :8000)
cd webapp && npm install && npm run dev
```
Откройте http://localhost:5173. Чтобы локально заработал и сам бот, укажите `BOT_TOKEN`. Чтобы открыть мини-апп из Telegram, нужен HTTPS-туннель (`cloudflared tunnel --url http://localhost:5173`); его адрес укажите в `WEBAPP_URL`.

## Команды бота

- `/start` — приветствие и подсказки
- `/app` — открыть мини-приложение
- `/report` — итоги дня прямо сейчас
- `/reset` — очистить контекст диалога с Claude (данные остаются)

## Стоимость Claude

Каждое сообщение — это 1–3 запроса к Claude: при записи данных вызываются инструменты. В системный промпт входит сводка вашего состояния (~1–2 тыс. токенов). Модель задаётся в `CLAUDE_MODEL`: Sonnet даёт оптимальный баланс, Haiku дешевле для простых записей, Opus лучше для сложного анализа.

## Что можно добавить дальше

- Миграции Alembic. Сейчас таблицы создаются при старте, поэтому при изменении моделей нужна миграция.
- Чтение QR-кода чека ФНС для точных данных без распознавания фото.
- Импорт банковских выписок (CSV/PDF).
- Еженедельный отчёт и графики расходов по дням.
- Webhook вместо polling при большом числе пользователей.

Claude не заменяет врача: бот не назначает лечение и рекомендует обращаться к специалисту по вопросам дозировок.
